## Todo List App (Go + React)

A basic full-stack todo list application with a Go (Golang) REST API backend and a React frontend.

## Features
- Create, list, update (toggle complete), and delete todo items.

- Simple REST API that the React UI consumes.

## Tech stack
Backend: Go (REST API).
Backend Framework: Gin
Frontend: React
Database: File System storage

## run script
Run backend server:
cd backend
go run server/main.go

Run frontend server:
cd frontend
npm run dev
